`windows-zones.json` contains Unicode CLDR's territory `001` Windows-to-IANA
calendar time-zone aliases, retrieved from:
https://github.com/unicode-org/cldr/blob/main/common/supplemental/windowsZones.xml

Used to interpret Outlook iCalendar `TZID` values. The associated Unicode license
is in `UNICODE-LICENSE.txt`. Named-zone transition data comes from `chrono-tz`.
