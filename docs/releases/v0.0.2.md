# Amigo v0.0.2

Amigo now includes a Markdown Journal alongside Tasks, Calendar, and Finance, with a redesigned interface, unified settings, and verified application updates.

## Changes

- **Journal:** a file-based notebook with folders, search, external Markdown files, root and folder creation actions, and a visible Trash with restore and permanent deletion. Folder operations preserve the full tree.
- **Markdown editing:** source, preview, and split layouts; editable preview with formatting controls; syntax-highlighted fenced code with language selection; formatting that respects existing Markdown; continuous bulleted, numbered, and task lists. Enter continues a list, Enter again on an empty item exits it, and Shift+Enter inserts a line break. Preview editing can be enabled by default in Journal settings.
- **Settings and appearance:** one settings window, Apple-inspired controls and grouped sections, improved spacing, compact notebook menus, and setup import/export in app settings.
- **Finance:** shared currencies, chains, and countries across vaults; consolidated vault configuration; a simpler currency list; removal of obsolete labels and duplicate Stored Values editors. Existing references migrate while retaining transaction links.
- **Updates and storage:** checks for published releases, verified downloads, and platform-specific installation/restart handling. Local libraries, encrypted Finance vaults, Journal drafts, and external-file conflicts retain their existing data protections.
- **Release tooling:** a reusable project release skill and package validation on all six native CI targets.

## Installation and runtime requirements

- **Linux:** install the RPM/DEB with your package manager, or make the AppImage executable and run it. Packages require glibc 2.35 or newer, a Wayland or X11 desktop, and working OpenGL/EGL drivers. Use `--appimage-extract-and-run` when FUSE is unavailable. RPMs explicitly require the Wayland libraries, including on Fedora 44.
- **macOS:** open the DMG and drag Amigo to Applications, or extract the app ZIP. macOS 12 or newer is required. Bundles are ad-hoc signed and are not Apple-notarized.
- **Windows:** run the per-user installer, or extract the portable ZIP and launch `Amigo/amigo.exe`. x86_64 builds target Windows 10 or newer; ARM64 packages are built on Windows 11. OpenGL-capable graphics drivers are required. Executables and installers are unsigned.

The library defaults to `~/.amigo` on Linux/macOS and `%USERPROFILE%\.amigo` on Windows. Set `AMIGO_HOME` to choose another location. Uninstalling preserves the library. Journal notes are plain Markdown files; optional Finance vault encryption applies to Finance data.

## Verification and source

All 14 packages are built natively from the same tagged source commit on Linux, macOS, and Windows for both architectures. Native CI runs formatting, Clippy, workspace tests, packaging-helper tests, and package builds. Validation checks package contents, executable architectures, bundled documentation, checksums, and clean source manifests. Linux jobs install and verify RPMs in clean Fedora 44 containers and compare extracted AppImages against the RPM/DEB payload. macOS jobs mount and verify DMGs and bundle signatures. Windows jobs install, compare the installed payload with the portable ZIP, and uninstall on disposable runners.

The downloaded Linux x86_64 packages are additionally smoke-tested in an isolated temporary library, including the AppImage under Wayland and X11. macOS and Windows container/install checks do not constitute interactive desktop testing.

Each target includes a `SHA256SUMS-…` file and `SOURCE-….json` recording the clean source commit and runtime requirements. Verify downloads against the matching checksum file. Build instructions and license notices are in the [README](https://github.com/0x626f/amigo/blob/v0.0.2/README.md). Source is available through the `v0.0.2` tag and GitHub source archives.
