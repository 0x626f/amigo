# Amigo v0.0.3

Amigo adds Squidy research boards, inline image/video previews, and more consistent editing across Tasks, Journal, and app settings.

## Changes

- **Squidy research boards:** organize named cards with briefs, Markdown data, colors, attachments, and saved positions. Create parallel connections and find paths with connection-title filters. New connections default to bidirectional; switch to Directed to follow From → To, or swap the endpoints. Existing connections without a direction field retain their previous directed behavior.
- **Readable paths:** selected routes highlight their cards and connections. A compact result strip shows tinted card names and connection labels with centered direction icons, wraps longer routes, and provides a close icon to clear the highlight.
- **Inline media:** display local PNG, JPEG, GIF, WebP, BMP, and TIFF images in Journal notes, Task descriptions, and Squidy cards. Optional FFmpeg tools provide video posters, playback, seeking, sound controls, and stopping. Attachments and portable Markdown references are included in setup backups.
- **Task interactions:** completed double-clicks reliably open task details, while ordinary dragging, double-click-and-hold dragging, and touchpad dragging remain available. Descriptions use single-click editing with an “Add a description…” placeholder; Escape cancels the description edit before closing the task draft.
- **Journal:** new notes and folders share the compact name dialog. Folder renaming preserves its subtree, expansion, and open descendants. Notebook tooltips show each name once without the extra Markdown extension.
- **Dialogs and configuration:** quieter headings, grouped fields, consistent actions, separate destructive styling, bounded scrolling, and improved initial focus and Escape handling. Accounts, Clients, and Chains use the same left-aligned row layout as Currencies.
- **Storage and updates:** Squidy snapshots and attachments participate in autosave, setup backup/restore, app close, and update preparation. Conflicting external changes preserve local drafts and saved files.

## Installation and runtime requirements

- **Linux:** install the RPM/DEB with your package manager, or make the AppImage executable and run it. Packages require glibc 2.35 or newer, a Wayland or X11 desktop, and working OpenGL/EGL drivers. Use `--appimage-extract-and-run` when FUSE is unavailable. RPMs explicitly require the Wayland libraries, including on Fedora 44.
- **macOS:** open the DMG and drag Amigo to Applications, or extract the app ZIP. macOS 12 or newer is required. Bundles are ad-hoc signed and are not Apple-notarized.
- **Windows:** run the per-user installer, or extract the portable ZIP and launch `Amigo/amigo.exe`. x86_64 builds target Windows 10 or newer; ARM64 packages are built on Windows 11. OpenGL-capable graphics drivers are required. Executables and installers are unsigned.

Inline video playback requires the optional FFmpeg tools `ffmpeg`, `ffprobe`, and `ffplay`. Install them on PATH or beside the application executable. Linux DEB/RPM packages recommend the tools; AppImage, macOS, and Windows packages do not bundle them. Image previews work without FFmpeg.

The library defaults to `~/.amigo` on Linux/macOS and `%USERPROFILE%\.amigo` on Windows. Set `AMIGO_HOME` to choose another location. Uninstalling preserves the library. Journal notes are plain Markdown files; optional Finance vault encryption applies to Finance data.

## Verification and source

All 14 packages are built natively from the same tagged source commit on Linux, macOS, and Windows for both architectures. Native CI runs formatting, Clippy, workspace tests, packaging-helper tests, and package builds. Validation checks package contents, executable architectures, bundled documentation, checksums, and clean source manifests. Linux jobs install and verify RPMs in clean Fedora 44 containers and compare extracted AppImages against the RPM/DEB payload. macOS jobs mount and verify DMGs and bundle signatures. Windows jobs install, compare the installed payload with the portable ZIP, and uninstall on disposable runners.

The downloaded Linux x86_64 packages are additionally smoke-tested in an isolated temporary library, including the AppImage under Wayland and X11. macOS and Windows container/install checks do not constitute interactive desktop testing.

Each target includes a `SHA256SUMS-…` file and `SOURCE-….json` recording the clean source commit and runtime requirements. Verify downloads against the matching checksum file. Build instructions and license notices are in the [README](https://github.com/0x626f/amigo/blob/v0.0.3/README.md). Source is available through the `v0.0.3` tag and GitHub source archives.
