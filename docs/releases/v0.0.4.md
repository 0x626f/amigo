# Amigo v0.0.4

Journal now reads and edits PDFs alongside Markdown, with draggable files, colored notes, and improved text and diagram editing throughout the app.

## Changes

- **PDF documents in Journal:** open PDFs temporarily without copying them, or save them to a Journal folder. Scroll continuously through pages, zoom, search, and fill supported forms. Add borderless text or notes; hover to read annotations, double-click to open them, and right-click to remove them. Note icons support preset and custom colors. Annotation edits and colors support Undo/Redo and persist inside saved PDFs. Passwords stay session-only; encrypted PDFs retain encryption.
- **Markdown to PDF:** convert a saved Markdown document into a separate PDF in its folder while preserving the original Markdown. PDF creation starts from an existing document; New Note still creates Markdown.
- **File organization:** move Markdown and PDF files with Move to Folder or drag them onto a folder in the Journal tree. Hover to expand closed folders, drop on NOTEBOOK or empty tree space to move to root, and press Escape to cancel. Moves preserve drafts and update the open document path; conflicts retain both files.
- **Long names:** scroll long names horizontally in navigation, headings, dropdowns, attachments, calendars, and Squidy cards. Inline Journal renaming follows the caret when navigating or typing, including after window resizing.
- **Journal editing:** more reliable continuation and exit behavior for bulleted, numbered, nested, and task lists; preview edits retain Markdown formatting, caret position, scrolling, and shared Undo history. Alt+F finds text and Alt+A selects all in editors.
- **Spelling and input:** automatic spelling suggestions, English/Spanish/Russian dictionary support, a personal dictionary, and a Dictionary context menu with Add to Dictionary and Fix to. Shared text inputs also offer emoji insertion.
- **Flowcharts:** render supported Mermaid flowchart syntax in Markdown, navigate diagrams by scrolling, zoom with Alt+wheel, and use controls on the right.
- **Squidy:** resize cards by their corners, create cards within the viewport, select multiple cards with Ctrl, and clear selection with Escape or an empty-area click. Double-click the board title to rename it. File Borders organize cards into named rectangular groups. Export a resizable capture area as an image-based PDF, with optional card text.
- **Settings and packaging:** Tasks settings navigate to an existing board; tool labels are shorter. Linux packages declare PDF runtime dependencies, and AppImages include the PDF rendering libraries.

## Installation and runtime requirements

- **Linux:** install the RPM/DEB with your package manager, or make the AppImage executable and run it. Packages require glibc 2.35 or newer, a Wayland or X11 desktop, and working OpenGL/EGL drivers. Use `--appimage-extract-and-run` when FUSE is unavailable. RPMs explicitly require the Wayland libraries, including on Fedora 44.
- **macOS:** open the DMG and drag Amigo to Applications, or extract the app ZIP. macOS 12 or newer is required. Bundles are ad-hoc signed and are not Apple-notarized.
- **Windows:** run the per-user installer, or extract the portable ZIP and launch `Amigo/amigo.exe`. x86_64 builds target Windows 10 or newer; ARM64 packages are built on Windows 11. OpenGL-capable graphics drivers are required. Executables and installers are unsigned.

PDF reading, forms, annotations, and Markdown conversion require Poppler GLib, Cairo, and Pango. Linux DEB/RPM packages install these dependencies; AppImages bundle them. The Ubuntu 22.04 Poppler runtime supports PDF reading and form filling but lacks the newer free-text APIs, so **Add Text** is unavailable in those AppImages. Notes and note colors remain available. On macOS, install `poppler` with Homebrew and make its libraries discoverable by the application; on Windows, provide the matching native runtime libraries beside the executable or in its `lib/` folder. macOS and Windows packages do not bundle these PDF runtimes. Missing runtimes show a visible error without changing the document. Scanned PDFs need an existing text layer for search; OCR, signing, and arbitrary page-content rewriting are not included.

Inline video playback requires the optional FFmpeg tools `ffmpeg`, `ffprobe`, and `ffplay`. Install them on PATH or beside the application executable. Linux DEB/RPM packages recommend the tools; AppImage, macOS, and Windows packages do not bundle them. Image previews work without FFmpeg.

The library defaults to `~/.amigo` on Linux/macOS and `%USERPROFILE%\.amigo` on Windows. Set `AMIGO_HOME` to choose another location. Uninstalling preserves the library. Journal documents are plain Markdown or PDF files; optional Finance vault encryption applies to Finance data.

## Verification and source

All 14 packages are built natively from the same tagged source commit on Linux, macOS, and Windows for both architectures. Native CI runs formatting, Clippy, workspace tests, packaging-helper tests, and package builds. Validation checks package contents, executable architectures, bundled documentation, checksums, and clean source manifests. Linux jobs install and verify RPMs in clean Fedora 44 containers and compare extracted AppImages against the RPM/DEB payload. macOS jobs mount and verify DMGs and bundle signatures. Windows jobs install, compare the installed payload with the portable ZIP, and uninstall on disposable runners.

The downloaded Linux x86_64 packages are additionally smoke-tested in an isolated temporary library, including the AppImage under Wayland and X11. macOS and Windows container/install checks do not constitute interactive desktop testing.

Each target includes a `SHA256SUMS-…` file and `SOURCE-….json` recording the clean source commit and runtime requirements. Verify downloads against the matching checksum file. Build instructions and license notices are in the [README](https://github.com/0x626f/amigo/blob/v0.0.4/README.md). Source is available through the `v0.0.4` tag and GitHub source archives.
